# Distribution and validation status

OxygenDynamicsV2 **3.1.0-rc.1** is a research software release candidate for the BOI Batch Editor. Its scope is recording setup, sequential analysis using the accepted BOI detector, saved results, and postprocessing exports. The [release notes](docs/RELEASE_NOTES_3.1.0_RC1.md) distinguish the workflow and measurement changes from both earlier releases and the original publication.

The candidate check uses MATLAB R2025a on macOS with synthetic fixtures. Recorded user testing of the CSV-to-automatic-to-compact workflow is separate from candidate verification. Performance and scientific interpretation across research cohorts, Windows desktop behavior, and compatibility with other MATLAB versions are outside the demonstrated scope.

The [original Science_2024 MIT notice](licenses/Science_2024-MIT.txt) accompanies inherited code. See [licensing and credits](LICENSING.md) and [third-party notices](THIRD_PARTY_NOTICES.md) for the applicable scope and dependencies.
