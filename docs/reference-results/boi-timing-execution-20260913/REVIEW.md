# Ten fixed timing review examples

These cases were selected before the new timing results. Start with examples 1 and 2. The review concerns whether an excursion is complete, partial or unresolved; exact manual boundaries are not required. The computational replay and plot checks are complete. Physiological interpretation and anatomical relevance remain open.

Black dashed lines show native detection bounds. Gray lines retain saved measurement/search bounds. Purple and green show negative and positive corrected runs; a boundary-limited line is not a confirmed recovery. Blue lines on the final two examples retain the researcher annotation ranges. Green dots in the source panel show available saved clean baseline samples, which may be fewer than the required 20.
