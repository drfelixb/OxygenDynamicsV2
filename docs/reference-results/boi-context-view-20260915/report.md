# Optional context view delivery

R5-CONTEXT-VIEW-087 — completed 21 September 2026.

The main MATLAB event viewer now has an Optional context tab. It calculates only
on request, keeps saved automatic intervals and current researcher alternatives
separate, preserves history and preferred/uncertain marks, and displays exact
accepted-reference frames independently from 10/20-sample diagnostic windows.
Missing support is unknown; native/human contacts are flags rather than exclusions.
The standalone context launcher supports legacy geometry from matching saved
native tables without rewriting original AnalysisInfo. Geometry evidence is hashed.
Exports contain the full calculation ingredients, source and implementation hashes.
