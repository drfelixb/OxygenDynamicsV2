To try the workflow in MATLAB, add `existing-analysis` to the path and open `OxygenDynamics_GUI`. Choose **BOI recording workflow**, then **Open saved run → Find in results folder** and navigate to the G2 `gui-run` folder above. The selected-run screen shows the source and outputs. Choose **Inspect event traces**, then select any sink or surge row. Stay on **Saved event evidence** for the preserved-input trace and baseline samples; the signed trace is unavailable when its baseline is unavailable. Open **Timing review** yourself for corrected intensity and its supporting detection score. **Export selected evidence** asks for a parent and writes a new event folder. Return to the selected-run screen for **Inspect recording results**, switch the sign, choose a window, and use **Export selected window evidence** for a separate new folder. **Open saved workbook** uses the path from the same indexed run. **New analysis** clears the selection and requires preflight and confirmation before any execution.
