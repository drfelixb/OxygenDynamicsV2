# OxygenDynamicsV2 4.0.0-rc.1 — 2026-11-27

## Changes

Compared with [3.1.0-rc.1](https://github.com/drfelixb/OxygenDynamicsV2/releases/tag/v3.1.0-rc.1), this candidate changes how paired sink depth is reported and retires several older workflows.

- The multichannel batch supports two independently analyzed oxygen channels or a fluorescence channel measured on oxygen-event footprints. Paired sink depth now uses the same saved automatic amplitude as the single-channel workflow, including negative values and values with flagged references. Both channel traces use the anchor sink’s saved reference frames. Paired summaries count flagged references and negative depths. To view or combine a pair saved under the earlier depth rule, rerun it into a new folder. [Multichannel guide](https://github.com/drfelixb/OxygenDynamicsV2/blob/release/4.0.0-rc.1/docs/BOI_MULTICHANNEL.md)
- Start the BOI Batch Editor with `openBOIBatchEditor`, a multichannel batch with `openBOIMultichannelBatch`, or pocket and nearby-tissue traces with `runPocketNearbyTissue` from the project folder. For other commands, first run `setupOxygenDynamicsPath`. Workflows, analysis code, developer tools, hypoxia-amyloid analysis and runtime definitions now have separate folders.
- The original launcher and wrapper, manual curation app, iOS and vascular analysis pathways, smoke and health checks, regression baselines and statistics acceptance tools have been retired. They remain available with the earlier development records in the [pre-cleanup snapshot](https://github.com/drfelixb/OxygenDynamicsV2/tree/pre-cleanup-20261124).
- Saved provenance now records the software version, source commit and checkout state. Re-exporting a saved calculation preserves its original identity when available and records the exporter separately.
- Compact workbook formatting now works with Java 8. The fix preserves workbook values. The automated check suite now runs 24 previously skipped test files. The release runbook and GitHub workflow add source ZIP and checksum verification, draft preparation and development-branch dry runs.

## Limitations

- Detection and measurement limits do not transfer between setups. Sink size limits, spatial averaging and the excluded border are fixed in pixels. Temporal smoothing is fixed in frames. Drift removal depends on recording length. Candidate thresholds and the automatic tissue area depend on the field of view. The software calculates depth, rise and burden without first subtracting a camera offset. Comparisons of depth and burden between cameras are therefore unsupported. [Issue #25](https://github.com/drfelixb/OxygenDynamicsV2/issues/25)
- The cutoff for linking pockets between channels is undecided. Reported links are candidates. [Candidate link definitions](https://github.com/drfelixb/OxygenDynamicsV2/blob/release/4.0.0-rc.1/docs/BOI_MULTICHANNEL.md#possible-counterparts-and-timing)
- Whether flagged sink references belong in between-channel comparisons is undecided. [Open researcher decisions](https://github.com/drfelixb/OxygenDynamicsV2/blob/release/4.0.0-rc.1/docs/SOFTWARE_DEVELOPMENT_PLAN.md#open-researcher-decisions)
- The pocket and nearby-tissue traces are under review. [Issue #21](https://github.com/drfelixb/OxygenDynamicsV2/issues/21)
- The demonstrated environments are macOS with MATLAB R2025a and Linux with MATLAB R2025b, as detailed above. Windows and other MATLAB releases are outside the demonstrated scope.
- The release checks use synthetic fixtures. Performance on new recordings, biological interpretation across cohorts and native file-chooser interactions remain outside their scope.
