## What the pilot tested

The pilot used archived primary proposals and raw 4 × 4 block means in frames 608–1114 for FB2413 and 5–839 for FB2412. Local time modes keep their own fixed block cohorts and candidate return searches. The comparison looks for an intervening return before a renewed decline and checks raw rise, absolute return and relative return separately. A common waveform fitted from disjoint surrounding patches allows their amplitudes to differ. The interpretation is repeated with each patch omitted in turn.

The surrounding patch rule uses geometric separation and archived signal confidence. Several selected patches have little overlap with saved analysis support, including a distant FB2413 patch with zero overlap and a nearby FB2412 patch with 3.3% overlap. This is a qualification of the comparator choice using the archived analysis mask. Together with the late context placement in both cases, it limits how confidently the pilot can assign a local or regional interpretation.
