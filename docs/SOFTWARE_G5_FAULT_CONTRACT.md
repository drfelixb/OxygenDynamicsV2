The script writes a one-use attempt marker **immediately before** each `ui.Run()`. If preflight, `which` identity, source hash, output absence or a stage guard fails, it stops; no extra attempt is authorized. The observer may use a process-exit fail-closed guard because the existing progress callback deliberately catches ordinary observer exceptions. A guard exit before the delegate could leave a `running` status; this is a safety stop and must be reported as untested rather than called a passing injected failure.

After both attempts, recovery uses only their saved artifacts and **new unused output path strings**; it does not start another run. Verify that direct reopen returns `OxygenDynamics:IncompleteRun`, the complete-run list excludes each folder, the GUI Run control stays disabled after failure/reopen, the failed-folder `RunStatus.json` hashes remain unchanged, a new output path can pass `Review settings`, and an existing G3 completed synthetic run still opens. Mid-stage cancellation/resume, engine-internal faults and real-acquisition failure behavior remain untested in this slice.
