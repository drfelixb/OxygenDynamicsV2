17 November 2026

The new OxygenDynamicsV2 contributions released with `v3.1.0-rc.1` are
cleared for public redistribution under the [MIT licence](LICENSE). The
original Science_2024 code retains its [original MIT notice](licenses/Science_2024-MIT.txt).
Bundled third-party components retain their component-specific terms in
[Third-party notices](THIRD_PARTY_NOTICES.md).

## Permission already supplied with the original software

The [Science_2024 release](https://github.com/Temp2Spec/OxygenDynamics_Public/tree/a3f4bee5d08f5f6000448a9be7b0059b9a4a6866)

`Copyright (c) 2023 Antonis Asiminas`. The corresponding
[Zenodo archive](https://doi.org/10.5281/zenodo.10629901) contains the same notice.
Its spelling and year are retained exactly.

MIT permits using, modifying, publishing and redistributing the covered software,
including commercially, provided the copyright and permission notice accompany
copies or substantial portions. A fresh permission request is ordinarily
unnecessary for those activities under the existing grant. See the
[MIT terms](https://opensource.org/license/mit).

This notice preserves the existing grant. It does not assign ownership or apply
a new licence to every file in the development checkout. Dependencies retain
their own terms in [Third Party Notices](THIRD_PARTY_NOTICES.md).

## Source records and archive metadata

The archived ZIP matches the checksum in the locally saved Zenodo record.
The restored licence is an exact copy of the archive's `LICENSE`; its full
commit, archive path and hashes are in the
[original software licence record](licenses/original-software-licence.json).

Zenodo's saved record metadata labels the deposit **CC BY 4.0**, while the code
archive and pinned GitHub release contain **MIT**. Both observations are retained.
This correction does not change the published metadata or infer the depositor's
intent, dual licensing, or the scope of material covered by that metadata label.
Keep the explicit MIT code notice and the original release reference when sharing
inherited code; any conflicting source-specific terms also remain relevant.
